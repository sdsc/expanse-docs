# Security Policy

## Reporting a vulnerability

Please report security issues privately:

- **Preferred:** use GitHub's private vulnerability reporting on this
  repository (**Security** tab → **Report a vulnerability**). If the button
  is not available, ask a repository admin to enable it under
  **Settings → Code security**.
- Alternatively, contact SDSC through the
  [SDSC Support](https://www.sdsc.edu/support/index.html) channels.

Please do not open public GitHub issues for security problems.

## Scope

This repository publishes a static documentation site
(<https://sdsc.github.io/expanse-docs/>) built with Docusaurus and deployed
through GitHub Actions to GitHub Pages. Issues in the site content, the
build workflows, or the published pages are in scope. Operational problems
with the Expanse system itself should go to the
[ACCESS Help Desk](https://support.access-ci.org/).
